# Идеи

## Виджет macOS

- Переделать дизайн виджетов: сделать их визуально более универсальными и единообразными в тёмной и светлой темах.
- Открывать приложение или подробное окно при нажатии на виджет.
- Добавить режим оформления «Системное»: автоматически переключать виджет между тёмным и светлым оформлением вслед за настройкой macOS.
- Сделать настройку содержимого виджета: только процент, процент и время сброса или все доступные окна.
- Добавить цветовую индикацию остатка: нормальный, предупреждающий и критический уровни.
- Показывать время последнего успешного обновления прямо в виджете по выбору пользователя.

## Уведомления

- Добавить настраиваемые уведомления о низком остатке лимита: включение, до пяти вручную заданных порогов в процентах (например, 15% и 10%) и проверка каждого доступного окна отдельно (5-часового и недельного).
- Уведомлять о восстановлении лимита после сброса.
- Добавить тихий режим: не показывать уведомления в заданные часы.
- Добавить предварительное уведомление перед сбросом лимита, если до него осталось выбранное время.

## Статистика и прогноз

- Рассчитывать прогноз исчерпания: когда лимит закончится при текущем темпе работы.
- Добавить историю расхода за 7 и 30 дней с графиком, пиковыми днями и средним расходом.
- Показывать сравнение текущего расхода с предыдущей неделей.
- Добавить дневной бюджет: пользователь задаёт желаемый остаток к концу недели, приложение показывает отклонение от плана.
- Добавить календарь сбросов и периодов повышенного расхода.
- Экспортировать историю и текущий снимок лимитов в CSV и JSON.

## Меню-бар и приложение

- Добавить настройку действия по нажатию на значок в меню-баре: открыть поповер, настройки или Codex.
- Сделать компактный режим с одним числом и индикатором направления: лимит расходуется или скоро сбросится.
- Добавить ручное обновление данных из меню-бара с видимым состоянием загрузки.
- Показывать в настройках источник данных, время последней успешной синхронизации и понятный текст ошибки CLI.
- Добавить кнопку копирования текущего статуса лимитов в буфер обмена.
- Добавить горячую клавишу для открытия подробного окна.

## Надёжность и совместимость

- Сохранять локальную историю снимков лимитов, чтобы статистика не пропадала после перезапуска приложения.
- Добавить режим работы без Codex Desktop: явно показывать состояние CLI и шаги восстановления авторизации.
- Добавить самопроверку после обновления Codex CLI: обнаруживать изменение формата данных и предлагать отправить диагностический отчёт без личных данных.
- Добавить кнопку «Сбросить локальные данные» с подтверждением для решения проблем с устаревшим снимком.
- Поддерживать несколько профилей Codex на одном Mac с явным переключением активного профиля.
