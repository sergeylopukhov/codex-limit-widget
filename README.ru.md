Codex Limit Widget выводит лимиты Codex в строку меню macOS и на рабочий стол, чтобы видеть остаток, не открывая Codex. Приложение показывает только те лимиты, которые есть у вашей учётной записи. Если лимит один недельный, пустого места под 5-часовой не будет; если доступны оба, на экране оба. Время сброса, тариф и статистика использования всегда перед глазами.

Пока приложение запущено, оно раз в минуту обновляет данные и передаёт свежий снимок в WidgetKit.

## Что показывает

- Все лимиты учётной записи: недельный и 5-часовой, если Codex его отдаёт.
- Время сброса каждого лимита.
- Тариф Codex понятным названием: `Plus`, `Pro 5x` или `Pro 20x`.
- Статистику: токены за всё время, пиковый день, расход за сегодня, серию дней подряд, самый долгий запуск и средний расход в день.
- График токенов за семь дней в большом виджете.
- Процент или подробную сводку в строке меню. Шкала под процентом по мере расхода меняет цвет от зелёного до тёмно-красного.
- Отметку об устаревших данных, если синхронизации не было дольше пяти минут, и время последней успешной синхронизации.
- Виджет в трёх размерах: маленький, средний и большой.
- Тёмное и бежевое оформление или системное, которое следует теме macOS.
- Русский или английский интерфейс либо язык системы.
- Уведомление и кнопку «Обновить», когда выходит новая версия.

## Установка

1. Скачайте последний `.dmg` со страницы [GitHub Releases](https://github.com/sergeylopukhov/codex-limit-widget/releases/latest).
2. Откройте его и перетащите `Codex Limit Widget.app` в `Applications`.
3. Запустите приложение.

Дальше приложение обновляется само (начиная с версии 1.1.8).

Требования:

- macOS 14 или новее.
- Codex CLI. Если его нет или вход не выполнен, приложение предложит установить CLI и войти.

Codex в настольном приложении ChatGPT не заменяет CLI: лимиты приложение читает через локальный Codex CLI. После вашего подтверждения оно само запустит официальный установщик CLI.

## Как добавить виджет

Откройте галерею виджетов macOS, найдите `Codex Limit Widget` и выберите размер.

Оформление виджета берётся из настроек приложения, и уже добавленные виджеты перекрашиваются сразу после смены. Когда рабочий стол закрыт окном, macOS делает виджет системным стеклом в любом оформлении.

## Строка меню

В строке меню можно показывать процент или подробную сводку. В режиме процента под числом идёт тонкая шкала остатка: при полном лимите она зелёная, к нулю становится тёмно-красной. Тем же цветом можно окрасить цифры. Для шкалы и цифр в настройках отдельные переключатели; по умолчанию цветная только шкала.

Действия по левому и правому клику настраиваются отдельно: контекстное меню, поповер, настройки или Codex. Из контекстного меню можно обновить лимиты, скопировать текущий статус и выйти из приложения.

В поповере видны оба лимита с цветными шкалами, время сброса и тариф. Кнопка «Копировать» кладёт в буфер тариф, процент и время сброса каждого лимита обычным текстом. Когда готово обновление, рядом с числом в строке меню появляется стрелка, а в поповере карточка обновления.

## Настройки

Настройки разложены по вкладкам:

- **Общие**: оформление (тёмное, бежевое или системное), язык и горячая клавиша для окна с подробными лимитами.
- **Строка меню**: показывать ли значок, режим процента или подробной сводки, цвет шкалы и цифр, какой лимит идёт в процент, действия по левому и правому клику.
- **Виджеты**: строка со временем синхронизации и действие по клику на виджет.
- **Уведомления**: предупреждения о низком остатке с отдельными порогами для каждого лимита и тихие часы.
- **Обновления**: установленная версия, итог последней проверки и кнопка обновления.
- **Диагностика**: состояние Codex CLI, источник данных, время последней успешной синхронизации, ответ CLI при ошибке обновления и кнопка «Сбросить данные».

«Сбросить данные» после подтверждения удаляет сохранённый снимок лимитов, данные виджета, историю уведомлений и настройки приложения. Учётную запись Codex и вход в CLI кнопка не трогает.

## Уведомления

У 5-часового и недельного лимитов свои переключатели и пороги, поэтому для каждого вы сами решаете, когда получить предупреждение. В тихие часы предупреждения о низком остатке не приходят, а сообщение о восстановлении лимита приходит как обычно.

Сообщение о восстановлении приходит только для лимита, который приложение само видело исчерпанным: оно должно было записать расход 100% и работать в момент, когда квота вернулась. Ещё для него нужно разрешение на уведомления, которое приложение запрашивает один раз.

## Обновления

Приложение проверяет последний публичный релиз на GitHub при запуске и потом каждые четыре часа. Проверить вручную можно в настройках.

О новой версии сообщают строка меню, поповер и настройки. После нажатия «Обновить» приложение скачивает официальный ZIP для macOS и сверяет контрольную сумму SHA-256 из GitHub, идентификатор пакета, версию и подпись кода. Если всё сходится, оно заменяет копию в `Applications` и перезапускается. После обновления окно «Что нового» показывает изменения с момента вашей прошлой версии.

Если записать в `Applications` не получается, нажмите «Открыть страницу релиза» и установите DMG вручную.

## Приватность

Данные об использовании и лимитах Codex остаются на Mac. Для виджетов хранится небольшой локальный снимок из сессии Codex CLI. При проверке обновлений в публичный API GitHub передаётся только номер установленной версии, без данных об использовании Codex. Собственного сервера у проекта нет.

## Удаление

Завершите Codex Limit Widget и удалите приложение из папки `Applications`.

Если после удаления виджет всё ещё виден в галерее, перезагрузите Mac и удалите другие локальные копии `Codex Limit Widget.app`.
